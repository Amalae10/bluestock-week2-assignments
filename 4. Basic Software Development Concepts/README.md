# Basic Software Development Concepts

## Objective

The objective of this assignment is to understand how web applications generate, process, store, and transfer data, and how that data eventually becomes available for analytics.

## Concepts Covered

### 1. Frontend

The frontend is the user-facing part of a web application. It allows users to interact with forms, buttons, pages, and other application components.

### 2. Backend

The backend processes requests from the frontend, performs business logic, communicates with databases, handles authentication, and returns responses.

### 3. Client–Server Architecture

The client sends requests to a server, and the server processes the request and returns a response.

### 4. REST APIs

REST APIs allow different components of an application to communicate using HTTP methods such as GET and POST.

### 5. Authentication

Authentication verifies the identity of a user. Examples include passwords, sessions, JWT tokens, and OAuth.

### 6. Databases

Databases store application data. Examples include PostgreSQL, MySQL, and SQL Server.

### 7. Data Pipelines

Data pipelines move data from source systems to analytical systems.

A common process is:

**Extract → Transform → Load (ETL)**

### 8. Logging and Monitoring

Logging records important application events such as API requests, user activity, errors, and system events.

Monitoring helps track application performance, availability, and potential problems.

### 9. Error Handling

Error handling allows applications to respond appropriately when something goes wrong, such as invalid requests, authentication failures, missing resources, or server errors.

### 10. Software Development Life Cycle (SDLC)

The basic SDLC process includes:

**Planning → Requirements → Design → Development → Testing → Deployment → Maintenance**

## Data Flow

The architecture diagram represents the following data flow:

**User Action → Frontend → Backend / REST API → Database → Data Pipeline → Analytics Dashboard**

Logging and monitoring are connected to the backend to track application events, errors, and performance.

## Data Analyst's Role

A Data Analyst may work with data generated by applications, query databases, validate data quality, analyze API data, work with data pipelines, and create dashboards for business users.
