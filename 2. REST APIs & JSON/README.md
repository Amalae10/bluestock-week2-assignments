# REST API & JSON Data Extraction

## Objective

To retrieve data from a public REST API, inspect the JSON response, convert it into CSV format, and perform basic data analysis.

## API Used

JSONPlaceholder

## API Endpoint

https://jsonplaceholder.typicode.com/users

## HTTP Method

GET

## Response Format

JSON

## Tools Used

- Postman
- Python
- Requests
- Pandas

## Process

API
→ GET Request
→ JSON Response
→ Python
→ Pandas DataFrame
→ CSV
→ Data Analysis

## Results

- Successfully received HTTP 200 response.
- Retrieved 10 user records.
- Converted JSON data into a Pandas DataFrame.
- Exported the data to CSV.
- Checked missing values.
- Performed basic company-level analysis.

## Output

api_users.csv

## Conclusion

This assignment demonstrates how REST APIs can be used to retrieve structured data and how Python and Pandas can be used to transform JSON responses into CSV datasets for further analysis.
